## ⚡ Knowledge Surface Management

The **Knowledge Surface** is the subset of AIOS that Tecnocrat exposes to the public:

```yaml
knowledge_surface:
  exposed:
    - hydrolang.concepts        # Core ideas, not implementation
    - security.architecture     # Design patterns, not vulnerabilities
    - evolution.results         # Successful experiments, not raw attempts
    - runtime.public_metrics    # Dashboards, not sensitive data
  
  hidden:
    - security.vulnerabilities
    - evolution.failed_experiments
    - runtime.internal_state
    - consciousness.raw_state
```

## 🔄 Content Pipeline

How AIOS artifacts become public content:

```
AIOS Artifact → Curator → Publisher → Public Content
     │              │           │            │
     │              │           │            └─ GitHub README, Portfolio, LinkedIn
     │              │           └─ Markdown/HTML/YAML transformation
     │              └─ Selection, filtering, abstraction level
     └─ Raw Hydrolang, Python, C++, internal docs
```

### Transformation Examples

| AIOS Artifact | Tecnocrat Transformation | Public Output |
|---------------|--------------------------|---------------|
| `AIOS_CORE.hydro` | Extract N-Layer concept | Portfolio "Architecture" section |
| `security/supercell` | Abstract design patterns | GitHub "Security" badge |
| `evolution_lab/results` | Curate successful demos | Blog post / interactive demo |
| `runtime_intelligence` | Select public metrics | GitHub stats / dashboard |
