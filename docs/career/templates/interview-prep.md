# Interview Preparation Checklist

## Company Research

- [ ] Read the company's About / Mission page
- [ ] Read recent blog posts or product release notes
- [ ] Scan engineering blog or GitHub org for style and tooling
- [ ] Understand their tech stack and how it maps to your skills

## Role-Specific

- [ ] Review job description — map required skills to your projects
- [ ] Prepare 3–5 stories (STAR: Situation, Task, Action, Result)
- [ ] Identify which AIOS/aios-trader features demonstrate required skills

## Technical

- [ ] Review data structures and algorithms basics (arrays, maps, sorting)
- [ ] Practice coding problems (LeetCode / AlgoExpert) — target easy/medium
- [ ] Review system design basics (HTTP, REST, databases, Docker)
- [ ] Prepare to explain AIOS architecture (supercell, consciousness primitives)
- [ ] Prepare to explain aios-trader architecture (daemon, strategies, risk management)

## Hands-on Project Discussion

- [ ] Walk through AIOS project architecture (C# core, Python AI layer, interface bridge)
- [ ] Walk through aios-trader architecture (daemon, attractor strategy, order registry)
- [ ] Review key PRs or issues you've worked on
- [ ] Explain decisions and trade-offs (why Docker, why consciousness primitives)

## Behavioral

- [ ] Strengths: self-directed learning, systems thinking, autonomous development
- [ ] Weaknesses: honest self-assessment + growth plan
- [ ] Conflict resolution: collaborative approach
- [ ] Teamwork: open-source engagement, AINLP protocol
- [ ] Learning: trajectory from sacred origins to current architecture

## Logistics & Follow-up

- [ ] Confirm timezone and equipment
- [ ] Test video/audio if remote interview
- [ ] Send a short thank-you note after the interview
- [ ] Update application tracker with interview outcome
