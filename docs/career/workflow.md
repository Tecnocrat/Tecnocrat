# 🛠️ Job-Hunting Workflow — Entry-Level Remote Dev Roles

> **Origin:** `Tecnocrat/Job-Hunting-Workflow` (absorbed Feb 2026)
> **Scope:** GitHub-integrated career pipeline

---

## 📅 Daily Routine

- **Search & Explore**
  - Visit curated repos: Remote Junior Developer Jobs Directory, Entry Level GitHub Jobs, ELD's Job Board, Tech Jobs Collections
  - Use GitHub search filters: `topic:remote-jobs`, `topic:entry-level`, `junior developer remote`
- **Check Issues & Discussions**
  - Look for open "help wanted" issues in repos you follow
  - Engage in discussions — recruiters sometimes post opportunities
- **Profile Visibility**
  - Pin a project that demonstrates your skills (modular documentation, Docker, AIOS)
  - Keep README current with "About Me" + contact links

---

## 📆 Weekly Routine

- **Update Portfolio**
  - Add one improvement to a pinned repo (feature, docs, or test coverage)
  - Ensure READMEs are consistent with Tecnocrat visual language
- **Networking**
  - Star repos related to jobs or career resources
  - Comment constructively on Issues or PRs to show collaboration
- **Track Applications**
  - Log applied jobs in `templates/application-tracker.md` (date, link, status)
  - Note feedback or recruiter responses

---

## 📅 Monthly Routine

- **Expand Reach**
  - Contribute small PRs to open-source projects (bug fixes, documentation)
  - Join GitHub organizations focused on junior devs or remote work
- **Audit & Reflect**
  - Review which repos yielded actual leads
  - Adjust search queries and repo subscriptions
- **Portfolio Refresh**
  - Archive outdated repos, highlight new ones
  - Align GitHub profile with current focus (AIOS, aios-trader, infrastructure)

---

## ✅ Workflow Checklist

| Step | Frequency | Action | Output |
|------|-----------|--------|--------|
| Search curated repos | Daily | Browse job repos | New job leads |
| GitHub keyword search | Daily | Use filters | Potential opportunities |
| Profile optimization | Daily | Update pinned projects | Stronger visibility |
| Portfolio improvement | Weekly | Add features/docs | Demonstrated growth |
| Networking | Weekly | Star/comment/engage | Increased visibility |
| Application tracking | Weekly | Log in tracker | Audit-ready record |
| Open-source contribution | Monthly | Submit PRs | Public collaboration |
| Audit & reflect | Monthly | Review effectiveness | Adjust workflow |

---

## ⚡ Integration

Treat each application as a "transaction" — log status like financial transfers:
- Applied → Interviewing → Offer / Rejected
- Project "pipeline health" from active applications vs. responses
- Cross-reference with `docs/cv/` for actual CV materials
