# 💼 Strategic Focus — Junior Dev Remote Job Search

## Targeting (1–2 hours)

- Pick roles matching your stack: React/JS (front-end), Node/Python (back-end), Docker/infrastructure
- Use GitHub search filters from `workflow.md` plus job boards:
  - We Work Remotely
  - Remotive
  - Wellfound (AngelList)
  - RemoteOK
  - LinkedIn (with remote + junior filters)

## Tailor Materials (30–90 mins per application)

- Copy `templates/resume-template.md` → tailor for specific role's tech stack
- Copy `templates/cover-letter-template.md` → address company + role specifically
- Reference actual CV PDFs from `docs/cv/` for consistency

## Apply & Track

- Log each application in `templates/application-tracker.md`
- Set follow-up reminders, update status flow:
  - **Interested** → **Applied** → **Interviewing** → **Offer** / **Rejected**

## Network

- Pin a GitHub project demonstrating relevant stack + concrete results
- Engage with open-source PRs or Issues — small, consistent contributions

## Interview Prep

- Use `templates/interview-prep.md` for structured preparation
- Practice: data structures, problem solving, system design basics
- Prepare STAR stories (Situation, Task, Action, Result)
