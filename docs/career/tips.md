# 💡 Career Tips & Privacy

## Best Practices

- Keep this section **private** — only store redacted or non-sensitive contact info
- Use a secure password manager or GPG encryption for PII and recruiter contacts
- Keep templates as single source of truth; archive old materials, don't delete
- Keep daily job-hunt tasks short and focused: apply 1–2 jobs, improve portfolio, or prep for an interview

## Privacy Rules

- Never commit real PII (phone numbers, addresses) to git
- Recruiter contacts: store in encrypted vault, not in tracked files
- If sharing any materials publicly, maintain a separate redacted branch
- Use `YYYY-MM-DD` date format consistently for all trackers and logs

## Profile Strategy

- Pin projects that demonstrate real skills and concrete results
- Keep GitHub profile (README.md) aligned with current career focus
- Portfolio website should mirror profile — single consistent narrative
- LinkedIn description should reference the same stack and projects
